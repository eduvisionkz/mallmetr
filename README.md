# MalMetr

**«Қой салмағын жанаспай анықтаудың математикалық моделі»** — цифровой продукт научного проекта.

MalMetr — устанавливаемое веб‑приложение (PWA) для Android и iPhone. Оно открывает настоящую камеру телефона, фиксирует кадр, определяет масштаб по измерительной рейке, вычисляет размеры тела овцы (H, L, D) по точкам, которые ученик ставит пальцем, и рассчитывает **предполагаемый** вес по выбранной математической модели. Интерфейс — на казахском языке. Регистрация не нужна, данные хранятся только на телефоне.

## Что внутри

| Раздел | Что делает |
|---|---|
| **ҚОЙДЫ СКАНЕРЛЕУ** | Камера (`getUserMedia`), рамка, подсказки, переключение камеры, кнопка «Кадрды бекіту». Индикатор качества кадра реально измеряет яркость и резкость (дисперсия лапласиана) — он **не** утверждает, что овца распознана. |
| **ФОТО АРҚЫЛЫ ӨЛШЕУ** | То же измерение по фото из галереи (если камера недоступна, приложение само предлагает этот путь). |
| Измерение | 4 шага: кадр → масштаб → размеры → результат. Зум двумя пальцами, перемещение, лупа при перетаскивании точки, отмена, поворот на 90°. |
| **МАТЕМАТИКАЛЫҚ МОДЕЛЬ** | Калькулятор с полным выводом: исходные размеры → формула → подстановка → промежуточные вычисления → итог. |
| **МОДЕЛЬ ҚҰРАСТЫРУ** | Модели A/B/C и свои формулы, ползунки коэффициентов, график M(H/L/D), версии моделей, сравнение ошибок, метод наименьших квадратов для линейной модели (от 5 записей с реальным весом). |
| **ЗЕРТТЕУ ЗЕРТХАНАСЫ** | Таблица ID / Күні / H / L / D / прогноз / факт / ошибка, графики, ручной ввод замеров рулеткой, экспорт CSV и PDF. |
| **НӘТИЖЕЛЕР** | История с фото, поиск, просмотр, редактирование точек, удаление, резервная копия JSON и восстановление. |
| **ЖОБАНЫ ҚОРҒАУ** | 11 слайдов защиты (тексты редактируются прямо в приложении), живые данные модели и лаборатории, кнопка «СКАНЕРДІ КӨРСЕТУ» открывает настоящий сканер. |

### AI көмекші (полуавтоматический режим)

Включается на главном экране: «AI көмекші → Қосу». Модель (~11 МБ: TensorFlow.js + COCO‑SSD MobileNet v2) скачивается **один раз**, дальше работает без интернета и хранится отдельно от кэша приложения.

| Шаг | Что происходит | Чем сделано |
|---|---|---|
| Камера | Рамка вокруг животного и надпись «Қой табылды · 87%» прямо в видео | Нейросеть COCO‑SSD (класс «sheep» из набора COCO) |
| Силуэт | На зафиксированном кадре выделяется контур животного (бирюзовая заливка) | Кластеризация цветов k‑means в пространстве Lab + морфология (`js/ai/segment.js`) |
| Рейка | Рейка находится автоматически, если она яркого цвета: красная/оранжевая, жёлтая или синяя, в том числе полосатая | Порог по цвету HSV + поиск вытянутой вертикальной области |
| Точки | Предлагаются 6 точек тела по силуэту, направление головы определяется автоматически (можно переключить: «сол жақта / оң жақта») | Геометрическая эвристика по профилю силуэта |
| Проверка | Ученик проверяет каждую точку и при необходимости сдвигает её | — |

**Для исследования.** В каждой записи сохраняются точки, предложенные AI, и размеры H, L, D по ним. В карточке результата видно расхождение «AI ↔ проверено» в сантиметрах. В лаборатории считается средняя |ΔH|, |ΔL|, |ΔD| и сколько точек в среднем пришлось исправлять. Эти же столбцы попадают в CSV. Это готовый материал для раздела «Автоматическая и ручная разметка: сравнение».

Чего AI не делает: не «угадывает» вес и не ставит точки наугад. Если животное не найдено, приложение прямо говорит об этом и предлагает ручную разметку. Если модель решила, что это не овца (например, «Сиыр» или «Жылқы»), это показывается честно.

### Математика

- Масштаб: `S = R / P` (см/пиксель), R — длина рейки, P — длина рейки на снимке.
- Вертикальные размеры H и D считаются **вдоль направления рейки**: `h = |(A − B) · u| · S`, где `u` — единичный вектор рейки. Поэтому небольшой наклон телефона не искажает высоту.
- Длина L: `√((x₂−x₁)² + (y₂−y₁)²) · S`.
- Рядом с каждым размером показывается оценка погрешности разметки (±2 пикселя на точку).
- Ошибка: `E = |Mпрогноз − Mфакт|`, `E% = E / Mфакт · 100%`. Если реальный вес не введён, ошибка не считается.

### Честные ограничения (заложены в интерфейс)

- Все коэффициенты стартовых моделей — **модельные**, не подтверждённые. Под каждым прогнозом написано: «Модельдік есептеу. Нақты өлшеумен тексерілмеген».
- Рейка и овца должны стоять на одинаковом расстоянии от камеры — иначе размеры будут неточными (приложение предупреждает).
- Нейросеть надёжно находит животное (это её задача), но **анатомические точки** вычисляются по силуэту эвристикой. Их точность на настоящих овцах ещё не проверена, поэтому каждая AI-точка помечена пунктирным кружком и значком «AI», пока ученик её не проверит.

## Запуск на компьютере

Нужен Node.js 18+ (или Python).

```bash
npm run dev          # откроется на http://localhost:5173
# или
python3 -m http.server 5173
```

Камера работает только по **HTTPS** или на `localhost`. Чтобы проверить на телефоне, опубликуйте на Vercel (ниже).

```bash
npm test             # проверка формул (масштаб, размеры, наклон, ошибки, МНК)
npm run build        # проверка, что все файлы для офлайн‑режима на месте
```

## Публикация на Vercel

**Через сайт (проще всего):**
1. Загрузите папку проекта в новый репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → выберите репозиторий.
3. Framework Preset: **Other**. Остальное подхватится из `vercel.json` (сборка `npm run build`, папка вывода — корень).
4. **Deploy**. Получите ссылку вида `https://malmetr.vercel.app` — она уже по HTTPS.

**Через терминал:**
```bash
npm i -g vercel
vercel          # первый раз — ответить на вопросы
vercel --prod
```

После публикации в разделе «Орнату» (карточка «Телефонға орнату» на главной) появится QR‑код ссылки — удобно для показа на защите.

## Установка на телефон

**Android (Chrome, Samsung Internet и др.):** открыть ссылку → кнопка «Орнату» в приложении или меню ⋮ → «Установить приложение» / «Добавить на главный экран».

**iPhone (Safari):** открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить». Инструкция есть внутри приложения.

Вид окна установки зависит от телефона и браузера — одинакового системного интерфейса на всех устройствах нет.

## Как проверить на телефоне (чек‑лист)

1. Открыть ссылку на Android и на iPhone.
2. «ҚОЙДЫ СКАНЕРЛЕУ» → разрешить камеру → должна открыться задняя камера. Запретить доступ → должна появиться инструкция и кнопка загрузки фото.
3. Снять предмет известного размера (например, дверь и рулетку) — сравнить результат с рулеткой. Это лучший способ проверить калибровку до выезда к овцам.
4. Поставить точки, перетащить их, отменить действие, повернуть фото.
5. Сохранить результат, открыть его в «Нәтижелер», ввести реальный вес → ошибка должна посчитаться.
6a. Включить AI көмекші (нужен интернет один раз), навести камеру на овцу → появится рамка «Қой табылды». Зафиксировать кадр → «Қойды тауып, нүктелерді ұсыну» → проверить и поправить точки.
6. Экспорт CSV, PDF (в окне печати выбрать «Сохранить как PDF»), резервная копия JSON и её загрузка.
7. Установить на главный экран, включить авиарежим → приложение, сохранённые фото, разметка и расчёты должны работать.
8. Проверить светлую и тёмную темы, поворот экрана.

В этой сборке приложение проверено автоматически в браузере Chromium (эмуляция телефона 390×844, тестовая камера, офлайн‑режим). AI проверен на фото и видео с лошадьми (снимков овец в среде разработки не было) и на синтетической «овце» в автотестах. **На реальных Android и iPhone оно ещё не тестировалось** — пункты выше нужно пройти вручную.

## Как снимать овцу для точного результата

- Рейка (например, 100 см) — строго вертикально, вплотную к боку овцы, в той же плоскости.
- Телефон — на уровне середины туловища, перпендикулярно боку животного, с расстояния 2–4 м.
- Овца стоит ровно, на ровной земле, все четыре ноги видны.
- Длинная шерсть увеличивает видимую глубину D — это стоит отметить в «Ескертпе» и обсудить в работе.
